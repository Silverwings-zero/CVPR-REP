# CVPR 2027 — tactile day-signature paper

- `main.tex` + `sec/*.tex`: the manuscript (CVPR author kit: `cvpr.sty`, `ieeenat_fullname.bst`, `preamble.tex`). Compile: `latexmk -pdf main.tex`.
- `numbers.tex`: GENERATED from the experiment results by `scripts/paper_numbers.py` in the HapTeleop repo
  (`PYTHONPATH=. .venv/bin/python scripts/paper_numbers.py`). Every number in the text is a macro; an undefined
  macro = a number with no run behind it. Do not edit by hand.
- `fig/*.pdf`: generated by `scripts/fig_*.py` in HapTeleop.
- `docs/CVPR_RESULTS.md`: results sheet (all tables with seeds and bootstrap intervals); `docs/CVPR_STORY.md`: story and abstract drafts.
- Run history with every number: `docs/TACREP_LOOP.md` in HapTeleop.
